# Contributing

Thank you for helping improve Cavuno MCP.

Use issues for connection problems, documentation gaps, client compatibility,
and proposals for public tool behavior. Do not include API keys, OAuth tokens,
customer data, non-public information, or vulnerability reports.

Report vulnerabilities privately as described in `SECURITY.md`.

Pull requests may improve the documentation, examples, and registry metadata.
Changes to server behavior should start as an issue so the MCP server, API
contract, CLI, SDK, and documentation can remain consistent.

By submitting a contribution, you agree that it may be distributed under the
MIT License and that you have the right to submit it.
